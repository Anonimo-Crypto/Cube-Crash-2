# Cube Crash

Juego arcade 3D en JavaScript puro.

## Modos de juego

| Modo | Descripción |
|------|-------------|
| **Clásico** | Endless con niveles, monedas y logros |
| **Casual** | No mueres, solo contador de cubos. Sin monedas ni logros |
| **Hearts** | 3 vidas. Niveles, puntuación, monedas y logros |
| **Desafiante** | Muchos más cubos, resistentes frecuentes, slow-mo débil, x2 monedas |
| **Legend** | En desarrollo |

## Logros
Desbloquea logros jugando y reclama las monedas en la pestaña **Logros**.

## Controles
- Mouse / Touch: deslizar para romper cubos
- P: pausar / reanudar
